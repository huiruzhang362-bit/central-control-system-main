# 组件设计规范（详细）

所有数值为硬性规范。目录：按钮 · 文字按钮 · 表格 · 分页 · **导航01（两级导航）** · **导航02（一级平铺导航）** · **页头** · 面包屑 · 弹窗与抽屉 · 表单与筛选行 · 图表统计 · 日期筛选 · tab 切换按钮 · toast 提示 · 异常/加载/空状态 · 标签/开关/徽标 · 卡片 · **切割队列进度卡片** · **甘特图与表单映射联动（P-03 右面板）** · 导出模式 · 通用交互

## 按钮

**类名结构**：骨架 `.btn` + 外观 `.btn-primary` / `.btn-ghost` / `.btn-danger` + 尺寸 `.btn-lg` / `.btn-sm` + 状态 `.btn-disabled`（或原生 `[disabled]`）。

> **`.btn` 骨架类必须写。** 只写 `class="btn-primary"` 时，按钮会退化成浏览器原生控件：**直角 + 黑边 + 默认字号**、高度不跟随 `--ctl-h`。看到「直角黑边按钮」先查这一个原因，不要先去调圆角。
> 交付 CSS 层已做兜底（骨架选择器同时包含 `.btn-primary/.btn-ghost/.btn-danger`），但业务代码仍按推荐写法写全，避免依赖兜底。

```html
<button class="btn btn-primary">默认按钮</button>
<button class="btn btn-primary btn-lg">新建加工任务</button>
<button class="btn btn-ghost btn-sm">导出 CSV</button>
<button class="btn btn-danger">批量删除</button>
```

**三档尺寸**：

| 档位 | 高度 | 左右内边距 | 类 | 用在哪 |
|---|---|---|---|---|
| 大 | 40px | 32px | `.btn-lg` | 页面级主操作：新建加工任务、下发排产、提交审核 |
| 默认 | 32px | 24px | 不写尺寸类 | 筛选区查询/重置、弹窗底部确定/取消 |
| 小 | 24px | 15px | `.btn-sm` | 表格行内操作、卡片头批量操作 |

**细节**：

- 字号统一 14px、Regular；圆角 4px。
- 主按钮：`#EE6402` 实底白字，hover `#FF7A45`。
- 描边按钮：1px `#d9d9d9` 描边、85% 黑文字；hover 描边与文字变 `#EE6402`。
- 危险按钮：**系统主色** `#EE6402` 实底白字，hover `#FF7A45`（2026-11-09 用户口径：删除类也走主色，不允许出现其他任意颜色）。用于删除、清空等不可逆操作。
- 禁用态：底色 `#f5f5f5`、1px `#d9d9d9` 描边、文字 25% 黑；且无 hover/click 颜色变化。
- 成对规范：「查询(主) + 重置(描边)」；「批量撤回(主) + 清空(描边)」。无筛选条件时重置 disabled 置灰。
- 图标与文字间距 8px；按钮内文字视觉上下居中（必要时用绝对/相对定位保证）。
- 尺寸只允许这三档，不要出现 36px、28px 这类中间值；需要中间值说明该改用模块作用域统一调，而不是单点写死。

**单个位置要特殊处理时，依次尝试**：
1. 换尺寸档位（`.btn-lg` / `.btn-sm`）——影响面最小；
2. 加模块作用域，让整块统一（见 SKILL.md「三级覆盖」）；
3. 只有全站基准确实不合适，才动 `:root` 的 `--ctl-h`。

## 文字按钮（link 型）

- 颜色 `#EE6402` + 常驻下划线；hover `#FF7A45`。
- 字号 14px、Regular；同列多个文字按钮间距 2–8px，整列纵向对齐不歪斜。
- 只有可点击状态给下划线与主色；纯展示文字不要。

## 表格

- 表头：14px Medium、85% 黑，背景浅灰，与内容列**左对齐**。
- 单元格：14px Regular、85% 黑，`white-space:nowrap` 单行不换行，长内容由横向滚动承接。
- 行 hover 浅灰底；选中行（复选框勾选）背景 `#FFF7E6`。
- 「已选 x 项」：文字 85% 黑、**数字 `#EE6402`**。
- 操作列靠右或紧跟内容列，列内按钮与表头「操作」对齐。
- 表格外层与卡片左右各留 24px。

## 分页（Figma「浅灰03」）

- 容器**右对齐**（`justify-content:flex-end`），字号 14px；单页（≤1 页）不显示；总页数 >2 时才显示页码选择。
- 页码项：32×32、白底、1px `#d9d9d9` 描边、圆角 2px、文字 14px/Regular/85% 黑；hover 文字 `#EE6402`（描边不变）。
- 当前页：**描边与文字 `#E27400`、字重 Medium(500)**、白底。
- 上一页/下一页：chevron 图标按钮，同 32×32 描边盒；不可用态图标 25% 黑、无 hover。
- 页数跳转框：高 32px、padding `0 8px 0 12px`、白底、1px `#d9d9d9`、圆角 2px、内阴影 `inset 0 -6px 8px rgba(0,0,0,0.02)`；文字「当前页/总页数」（如 `3/123`）14px/25% 黑；下拉箭头 SVG 10.18×6.86、25% 黑，展开时旋转 180°。
- 页码下拉列表**向上弹出**：白底、1px `#d9d9d9`、圆角 2px、阴影 `0 6px 16px rgba(0,0,0,0.08)`；项高 32px、padding `0 12px`、hover 底 `#FDF4E7` + 文字 `#EE6402`。
- 只显示页码，**不显示“共 N 条”**，不出现英文 page/items。
- 切换页码时当前表单不来回抖动；数据未就绪可显示加载态（圆点动效，主色 #EE6402）。

## 导航01 · 两级导航（父子树形）

> 与「导航02 · 一级平铺导航」并列两种导航形态，视觉基调统一：项高 44px、字号 16px、强调色 #EE6402；结构差异见导航02 章节末的对比表。

- 宽度 230px；父级/子级按钮高度与设计稿一致，字号 16px。
- 父级**默认全部展开**；手风琴：同一时间只展开一个父级，选中子级时父级不可收缩，点其它父级才收起上一个。
- 父级状态：展开未选中=黑灰文字+icon、箭头**向上**；展开选中（子级被选中）=文字+icon `#EE6402`、背景 `#FDF4E7`、字重 500、箭头向上；折叠=子级隐藏、箭头**向下**，再次点击才展开。
- 子级状态：默认 65% 黑、无 icon、左缩进对齐；选中=主橙+`#FDF4E7` 底+500，父级同步选中；hover=浅灰底。
- 收缩模式只显示父级 icon（子级无 icon），不收叠文字、不重影。
- 内容溢出时显示滚动条，滚动条定位在最右侧、**不改变按钮宽度**（无抖动）。
- 导航宽度变化时右侧内容自适应拉伸。

## 弹窗与抽屉

两者结构相同：**头部 + 内容 + 底部操作** 三段式固定，内距走同一套 token，只是出现方式不同（弹窗居中、抽屉贴右）。

### 弹窗 Modal

**宽度只有四档**，按内容复杂度选档，不写 500 / 600 这类中间值（需要中间值说明该走模块作用域统一调）。旧项目里 `--modal-w: 360px` 是确认弹窗宽度，现改为 `--modal-w-sm: 420px`，接入时一并替换：

| 档位 | 类 | 宽度 | 用在哪 |
|---|---|---|---|
| 确认 / 提示 | `.modal-sm` | 420px | 删除确认、无法删除：一段说明 + 两个按钮 |
| 表单（默认） | `.modal` | 640px | 新建 / 编辑表单，两列布局 |
| 详情 | `.modal-lg` | 820px | 只读详情、参数条 + 预览图 |
| 大表 / 日志 | `.modal-xl` | 1080px | 解析日志、批量清单、整套料图 |

**容器**：圆角 12px（`--radius-card`）、页面上下左右居中（不是 antd 默认 `top:100px`）；最高 `calc(100vh - 64px)`，超出由弹窗内部滚动，不顶出视口。

**头部**：内距上下 16 / 左右 24（`--modal-head-py` / `--modal-pad-x`），下接 1px `#f0f0f0` 分隔线。标题 16px Medium、85% 黑，与卡片头同规格，不重复正文内容。右上角关闭 **24×24 热区**（图标 14px、45% 黑），hover 主橙 + 8% 橙底；**不要放大图标、不要加描边**。

**内容**：距头部 20px（`--modal-body-mt`）、左右 24px。多块内容之间 16px（`.modal-stack`），页面里不再写 `mb-4` / `mt-5` 这类魔法间距。表单走两列网格：列距 24 / 行距 24 / 标签与控件 8（`.modal-form`），标签 14px `#595959`。弹窗内表格正文 **14px**（antd `size="small"` 会掉到 13px，必须显式改回）。内容超长用 `.modal-scroll`（`max-height:52vh`、1px `#d9d9d9` 描边、圆角 4）。

**底部操作区（footer）只有一个形态**：

- 距内容 24px（`--modal-foot-mt`），左右与下 24px。
- 右对齐、**两个按钮**、取消（描边）在左 + 主操作（橙实底）在右、相邻间距 **12px**（`--modal-foot-gap`）、不加分隔线。
- 主操作文案用动词（保存并提交 / 确认删除 / 创建），不用「确定」这种无信息量词。
- **禁止**：三个及以上按钮、把「取消」做成右侧文字链接、只留单边按钮（纯提示型弹窗除外，此时只保留主操作「知道了」）。
- 对应 antd 写法：用默认 footer（`okText` / `cancelText`），不要传自定义 `footer`；只读详情才传 `footer: null`。

**三种形态**：

1. **确认类**（删除等不可逆操作）：橙警示图标 16px（`#EE6402`，`margin-top:3px` 让图标与 22px 行高首行视觉对齐）+ 85% 黑说明 + 取消/主操作。**不要用 `Alert type="error"` 做删除确认** —— 红底 `#fff2f0` / 红图标 `#ff4d4f` 是「加载失败提示条」的样式；`#ff4d4f` 实底只用于页面级批量删除按钮。
2. **提示类**（无法删除、校验拦截）：同结构，footer 只留一个主操作「知道了」。
3. **表单类**：`.modal` 640 起，顶部可放一条信息提示条，表单两列，footer 两个按钮。

**遮罩**：与抽屉共用 `.scrim`（`rgba(0,0,0,0.45)`），弹窗底下不能是透明或浅灰 —— 打开即压暗页面，点击遮罩关闭（确认类弹窗 `maskClosable={false}` 例外）。

全站禁止残留蓝色主按钮（如「撤回」用橙 `#EE6402` 实底）。

### 抽屉 Drawer

| 档位 | 类 | 宽度 | 用在哪 |
|---|---|---|---|
| 窄 | `.drawer-sm` | 480px | 筛选面板、单列表单、简短详情 |
| 默认 | `.drawer` | 640px | 详情 + 操作混排（异常处理、任务详情） |
| 宽 | `.drawer-lg` | 800px | 抽屉内嵌表格、多列对比 |

- 与原站「查看流程」抽屉完全同参：本体 **90% 白半透底** `rgba(255,255,255,0.9)` + `backdrop-filter: blur(6px)`，页面内容在抽屉下隐约透出；顶部 1px `#D9D9D9` 描边；**直角、无投影、无圆角**（不要套 12px 圆角或卡片阴影）。
- 从右侧滑出、贴视口右缘；有全局页头时抽屉顶到页头下沿（`top: 64px`、高 `calc(100% - 64px)`），遮罩同步让位。
- **标题条（全站统一外观，不许换成白底）**：
  - 几何：高 `36px`、距抽屉顶 `25px`、左侧留 `24px`、**右端出血贴抽屉边缘**；
  - 底图：`drawer-header-bg.png`（617×36，深灰 `#3D3D3D`、**alpha 左实右透渐变：左端不透明 → 右端 ~3%**），`background-size: 100% 100%` 拉满；右端透出页面内容形成「渐变」效果——**底下不垫任何实底色**（垫色会把透明度填死，实测踩过），渐变来自半透明而非颜色；
  - 左侧 `5px` 橙条 `#EE6402`（`border-left` 实现），整条圆角 `2px`；
  - 标题：白 `#FFF`、`14px Medium`、行高 24px、左对齐；条内副信息白 72%、超长省略；
  - 关闭按钮：`24×24` 方形透明底、图标 `14px`、`rgba(0,0,0,0.65)`，hover 橙字 + 8% 橙底，focus 橙描边；不要放大图标、不要加描边。
- **遮罩（必显）**：`var(--scrim)` = `rgba(0, 0, 0, 0.45)`，统一取 `.scrim`，页面里不要再手写 `rgba(0,0,0,.45)` 或自建遮罩类。
  - 覆盖 `inset: 0` 铺满视口；有全局页头时整体让位一个页头高（`top: 64px`），与抽屉上沿齐平，**不允许盖住页头**。
  - 层级：遮罩 `40` < 抽屉 `50`，遮罩只压页面内容，不能盖住浮层本身。
  - 交互：点击遮罩或 Esc 关闭，遮罩与抽屉同时 300ms 淡出；不要做无遮罩的「浮动侧栏」。
  - antd 写法：直接 `Drawer` 用自带 `mask`（默认 `rgba(0,0,0,0.45)`），只通过 `rootClassName` 调 `top`，**不要 `mask={false}`**，也不要手写 `<div class="mask">`。
- 内容区：正文 14px、内距 `8px 24px 24px`（`--drawer-pad`）。**只有 `.drawer-body` 能滚**（`flex:1 1 auto` + `overflow:auto`，滚动条贴抽屉右缘），头部与底部固定；抽屉内不要再套第二个滚动容器。
- 底部：右对齐、取消 + 主操作、间距 12px；上描边 1px `#F0F0F0`、内距 `12px 24px 16px`；footer 背景**透明**（透出抽屉 90% 白底，不单独铺白）。
- 宽度用整数，按内容复杂度选档；抽屉本身即容器，内容不要再套一层卡片阴影。
- antd 写法：全站抽屉共用同一套外观（`rootClassName` 挂 `exception-drawer`），标题条样式只写一次全部继承；`box-shadow: none`、`content-wrapper` 同步 `top: 64px`。

## 甘特图与表单映射联动（P-03 右面板承载）

甘特**不是独立组件**，是「计划列表页」右面板的一部分（面板头 54 → 甘特卡 → 工单表 → 分页）。样式与结构逐值取自中控系统项目（`.plan-gantt` / `.pg-*` / `.plan-detail` / `.sched-dot`）：

**对应关系契约**：

| 甘特段 | 表单字段 | 规则 |
|---|---|---|
| 段所在机器行 | 「切割机」 | 段只落在其所属机器行（C1/C2/C3 三行常显，空行留白） |
| 段左右边界 | 「开始 / 结束时间」 | 段宽 = 时长；段间 2px 白缝（左右各让 1px） |

**视觉（项目实测）**：

- 甘特卡：padding 4 8 6、渐变底 `linear-gradient(180deg,#F2F4FB,#FAFBFE)`、下边线 1px `#D9D9D9`；标题「排产甘特图」14px/500 `#262B38`。
