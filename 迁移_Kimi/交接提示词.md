# 项目交接 · 型材立库中控系统（ROBIM PCCS 前端原型）

你现在接手这个项目。下面是你需要知道的全部内容；其中"第一步"的读取任务请先完成，**不要提前写代码**。

## 〇、这个项目是什么

单文件、零构建、纯前端的**工业中控系统 UI 原型**。业务场景是钢构/船舶车间的型材立库 + 切割产线：型材（角钢/型钢）按「船号 + 分段号 + 程序号」组织成切割包，从立库出库后经过喷码、去底漆、切割、分拣五道工序。

关键定性：**全部是演示用假数据**，无后端、无真实接口、无鉴权、无移动端适配。定位 1920×1080 桌面浏览器 / 工业大屏。它的价值在于"双击 HTML 就能演示完整业务闭环"，给设计师和业务方评审 UI 与交互。

理解这一点很重要 —— 它不是一个要上生产的系统，任何"工程化改进"都会破坏它的核心交付价值。

### 定位代码的方式

**用符号名搜索，不要按行号跳。** `项目档案.md` 里的行号基于 2026-10-22 版本，这几轮改动后已经漂移。常用符号：`NAV_ITEMS`（导航配置）、`renderPage`（页面路由 switch）、`KB_STATUS_SEQ`（13 态加工状态机）、`ProcessingQueueGantt`（切割队列甘特）、`useMsg`（提示策略层）、`AppInner`（应用外壳）。

### 跨页数据怎么走

## 四、约束与约定

### 五条铁律（违反会直接破坏演示可用性）

1. **不引入构建流程**。禁止 JSX / Babel / npm / Vite / Webpack。全部组件用 `React.createElement` 手写，"双击 HTML 就能跑"是核心交付价值。
2. **不改 `<script>` 引入顺序**：`react → react-dom → dayjs → antd → 加工任务_假数据.js → 排产_输入数据.js → 排产_算法.js → data.js → 主脚本`。错一个直接白屏。
3. **不在 `data.js` 与主脚本里重复声明同名全局变量**（两者同处全局作用域，重名即 `SyntaxError`）。
4. **不擅自升级 React / antd 版本号**（18.3.1 / 5.29.3）。本地 UMD 是离线演示的基础。
5. **不删除、不重命名中文文件名**。多个 HTML 通过百分号编码的中文路径互相引用（含 iframe）。

### 设计规范（强约束）

| Token | 值 |
|---|---|
| 主色 | `#EE6402`（hover `#FF7A45`） |
| 页面底色 | `#F8F9FA` |
| 正文色 | `rgba(0,0,0,0.85)`（全站不用纯黑） |
| 圆角 | `0`（工业风直角） |
| 字体 | Source Han Sans CN / PingFang SC |

强制规则：**全站禁止残留蓝色**（`#1677ff` 等 antd 默认值一律换主橙）；**弹窗 footer 最多 2 个按钮**（取消描边 + 主操作橙实底），次操作放步骤行右侧或内容区右上。写 UI 前查 skill 的 `references/components.md` 对应组件章节。

### 提示（toast / 弹窗）策略

全站轻提示已收敛到 `useMsg()` 策略层，**不要在各调用点各弹各的**。分级：L0 error（阻断型，必留）、L1 warning（操作被驳回或存在业务风险，必留）、L2 info（某动作的唯一反馈，必留但缩短）、L3 success（纯回执，默认静默）。

**低等级删除不做二次确认**（工单、文件、用户/角色/班次/日志、撤回）：点击即执行 + toast 回执。仅「下发」这类不可逆业务动作保留确认弹窗。加新提示前先判断它属于哪一级，别直接 `msg.success`。

### 协作规约（这个项目可能有两个 AI 交替维护）

1. **单写者**：同一时刻只有一方改 `中控系统.html`。两个 AI 同时改会产出互不兼容的版本，没有自动合并能力。开工前先确认这轮由你改。
2. **进度只认 `AGENTS.md §7`**：改完更新它（版本号 + 一行变更 + 日期），30 秒内完成。**不要另建 `工作日志.md` / `CHANGELOG.md`**，多一个状态源就多一处漂移。项目档案 §8/§11 是深度档案，只在架构/契约/模块级变化时才动。
3. **交付包同步是硬动作**：`cp 中控系统.html 中控系统_交付包/中控系统.html`，然后比对 md5。漏一次就是把旧版发出去（已踩过，差 234 行）。
4. **临时产物不进项目根**：无头验证的探针 HTML、截图一律放 `/tmp`。项目根曾堆过 7 个 `_p*.html` 共 2.8 MB。

### 验证纪律（这条省不掉，历史上吃过亏）

- 必须在**用户真实视口尺寸** + **真鼠标事件**下验，不要只跑 `--dump-dom` 探针或矮窗口。曾因用小窗口验证，导致"吸顶/间距"类问题反复漏修。
- 工具用 `agent-browser`（真 Chromium，支持 `set viewport` / `click` / `eval` / `screenshot`）。
- 用户说"这里间隙/错位"时，先从他截图的**像素坐标**反推对应 DOM 区间，再谈改法。
- 无头浏览器连续 `eval` 会漂到 `about:blank`，把整串交互塞进单次 `eval` 里跑。
- 中文目录下 `file://` 有时取不到文档，验证时复制到 `/tmp` 下的纯 ASCII 路径。
