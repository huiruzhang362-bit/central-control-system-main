型材立库中控系统 · 交付包
=============================

版本:v10.12-57 (2026-10-31)

说明
----
本目录是扁平化可分发演示包：主页面 + 本地依赖 + 假数据，无任何构建步骤、无外网引用。

使用方法
--------
1. 直接双击「中控系统.html」（推荐 Chrome / Edge）。
2. 或在 Mac 上双击「启动演示服务.command」，然后访问 http://localhost:8088 。

目录内容
--------
- 中控系统.html        主应用（全部页面 / 组件 / 样式 / 交互）
- react.min.js 等 5 个   本地依赖（react / react-dom / dayjs / antd js+css），勿改版本
- data.js / 加工任务_假数据.js / 排产_输入数据.js / 排产_算法.js
                      演示数据与排产算法（全部为假数据）
- 启动演示服务.command   无缓存静态服务器（端口 8088）

- v10.12-44 (2026-10-30)  左侧导航滚动抖动治理 + 分段控件同心圆角：

                               （正好是整数槽位），滚动全程像素级静止。

                               把每个标题的「自然偏移 base」缓存起来（只在布局变化时测一次），
