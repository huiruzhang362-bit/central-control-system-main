# 组件设计规范（详细）

所有数值为硬性规范。目录：按钮 · 文字按钮 · 表格 · 分页 · 左侧导航 · 面包屑 · 弹窗与抽屉 · 表单与筛选行 · 图表统计 · 日期筛选 · tab 切换按钮 · toast 提示 · 异常/加载/空状态 · 标签/开关/徽标 · 卡片 · 导出模式 · 通用交互

## 按钮

**类名结构**：骨架 `.btn` + 外观 `.btn-primary` / `.btn-ghost` / `.btn-danger` + 尺寸 `.btn-lg` / `.btn-sm` + 状态 `.btn-disabled`（或原生 `[disabled]`）。

> **`.btn` 骨架类必须写。** 只写 `class="btn-primary"` 时，按钮会退化成浏览器原生控件：**直角 + 黑边 + 默认字号**、高度不跟随 `--ctl-h`。看到「直角黑边按钮」先查这一个原因，不要先去调圆角。
> 交付 CSS 层已做兜底（骨架选择器同时包含 `.btn-primary/.btn-ghost/.btn-danger`），但业务代码仍按推荐写法写全，避免依赖兜底。

```html
<button class="btn btn-primary">默认按钮</button>
<button class="btn btn-primary btn-lg">新建加工任务</button>
<button class="btn btn-ghost btn-sm">导出 CSV</button>
<button class="btn btn-danger">批量删除</button>
```

**三档尺寸**：

| 档位 | 高度 | 左右内边距 | 类 | 用在哪 |
|---|---|---|---|---|
| 大 | 40px | 32px | `.btn-lg` | 页面级主操作：新建加工任务、下发排产、提交审核 |
| 默认 | 32px | 24px | 不写尺寸类 | 筛选区查询/重置、弹窗底部确定/取消 |
| 小 | 24px | 15px | `.btn-sm` | 表格行内操作、卡片头批量操作 |

**细节**：

- 字号统一 14px、Regular；圆角 4px。
- 主按钮：`#EE6402` 实底白字，hover `#FF7A45`。
- 描边按钮：1px `#d9d9d9` 描边、85% 黑文字；hover 描边与文字变 `#EE6402`。
- 危险按钮：`#ff4d4f` 实底白字，hover `#ff7875`。用于删除、清空等不可逆操作。
- 禁用态：底色 `#f5f5f5`、1px `#d9d9d9` 描边、文字 25% 黑；且无 hover/click 颜色变化。
- 成对规范：「查询(主) + 重置(描边)」；「批量撤回(主) + 清空(描边)」。无筛选条件时重置 disabled 置灰。
- 图标与文字间距 8px；按钮内文字视觉上下居中（必要时用绝对/相对定位保证）。
- 尺寸只允许这三档，不要出现 36px、28px 这类中间值；需要中间值说明该改用模块作用域统一调，而不是单点写死。

**单个位置要特殊处理时，依次尝试**：
1. 换尺寸档位（`.btn-lg` / `.btn-sm`）——影响面最小；
2. 加模块作用域，让整块统一（见 SKILL.md「三级覆盖」）；
3. 只有全站基准确实不合适，才动 `:root` 的 `--ctl-h`。

## 文字按钮（link 型）

- 颜色 `#EE6402` + 常驻下划线；hover `#FF7A45`。
- 字号 14px、Regular；同列多个文字按钮间距 2–8px，整列纵向对齐不歪斜。
- 只有可点击状态给下划线与主色；纯展示文字不要。

## 表格

- 表头：14px Medium、85% 黑，背景浅灰，与内容列**左对齐**。
- 单元格：14px Regular、85% 黑，`white-space:nowrap` 单行不换行，长内容由横向滚动承接。
- 行 hover 浅灰底；选中行（复选框勾选）背景 `#FFF7E6`。
- 「已选 x 项」：文字 85% 黑、**数字 `#EE6402`**。
- 操作列靠右或紧跟内容列，列内按钮与表头「操作」对齐。
- 表格外层与卡片左右各留 24px。

## 分页（Figma「浅灰03」）

- 容器**右对齐**（`justify-content:flex-end`），字号 14px；单页（≤1 页）不显示；总页数 >2 时才显示页码选择。
- 页码项：32×32、白底、1px `#d9d9d9` 描边、圆角 2px、文字 14px/Regular/85% 黑；hover 文字 `#EE6402`（描边不变）。
- 当前页：**描边与文字 `#E27400`、字重 Medium(500)**、白底。
- 上一页/下一页：chevron 图标按钮，同 32×32 描边盒；不可用态图标 25% 黑、无 hover。
- 页数跳转框：高 32px、padding `0 8px 0 12px`、白底、1px `#d9d9d9`、圆角 2px、内阴影 `inset 0 -6px 8px rgba(0,0,0,0.02)`；文字「当前页/总页数」（如 `3/123`）14px/25% 黑；下拉箭头 SVG 10.18×6.86、25% 黑，展开时旋转 180°。
- 页码下拉列表**向上弹出**：白底、1px `#d9d9d9`、圆角 2px、阴影 `0 6px 16px rgba(0,0,0,0.08)`；项高 32px、padding `0 12px`、hover 底 `#FDF4E7` + 文字 `#EE6402`。
- 只显示页码，**不显示“共 N 条”**，不出现英文 page/items。
- 切换页码时当前表单不来回抖动；数据未就绪可显示加载态（圆点动效，主色 #EE6402）。

## 左侧导航

- 宽度 230px；父级/子级按钮高度与设计稿一致，字号 16px。
- 父级**默认全部展开**；手风琴：同一时间只展开一个父级，选中子级时父级不可收缩，点其它父级才收起上一个。
- 父级状态：展开未选中=黑灰文字+icon、箭头**向上**；展开选中（子级被选中）=文字+icon `#EE6402`、背景 `#FDF4E7`、字重 500、箭头向上；折叠=子级隐藏、箭头**向下**，再次点击才展开。
- 子级状态：默认 65% 黑、无 icon、左缩进对齐；选中=主橙+`#FDF4E7` 底+500，父级同步选中；hover=浅灰底。
- 收缩模式只显示父级 icon（子级无 icon），不收叠文字、不重影。
- 内容溢出时显示滚动条，滚动条定位在最右侧、**不改变按钮宽度**（无抖动）。
- 导航宽度变化时右侧内容自适应拉伸。

## 面包屑

- 字号 14px/Regular；包含在内容区背景内，背景与页面一致（不要白色浮块）。
- 父级：rgba(0,0,0,0.45)、可点击可追踪（cursor pointer、hover `#EE6402`）；上一级没有页面时只显示当前项，不乱跳转。
- 分隔符：chevron SVG（18×18、stroke currentColor、颜色 rgba(0,0,0,0.68)），左右间距 8px，与文字垂直居中对齐。
- 当前项：rgba(0,0,0,0.85)。

## 弹窗与抽屉

- 弹窗圆角 12px、相对整个页面居中；右上角必须有关闭按钮（关闭按钮定位不要额外 right:24px 叠加错乱）。
- 页头标题与全站卡片头标题同规格（85% 黑）；标题不重复正文内容。
- 内容区与页头间距 **margin-top 20px**。
- 危险确认弹窗统一：警示图标（`#EE6402`，与首行文字上下对齐）+ 标题 + 说明 + 取消/主操作（橙实底）。
- **底部操作区（footer）只有一个形态**：右对齐、**两个按钮**、「取消（描边）在左 + 主操作（橙实底）在右」、`gap 8px`、**不加分隔线/边框**、垂直内边距 `12px 24px 20px`。主操作文案用动词（保存并提交 / 确认删除 / 创建），不用「确定」这种无信息量词。
- footer 里**禁止**：三个及以上按钮、把「取消」做成右侧文字链接、单边按钮（只有确定没有取消，除非是纯提示型弹窗）。
- 对应 antd 写法：`okText` / `cancelText` 用默认 footer 即可，不要传自定义 `footer`（除非是只读详情弹窗，传 `footer: null`）。
- 全站禁止残留蓝色主按钮（如「撤回」用橙 `#EE6402` 实底）。
- 信息/警示 Alert：底色 `#FFF7E6`、描边 `#FFE7BA`、图标 `#EE6402`、关闭图标与首行文字顶部对齐。
- 抽屉宽度给整数（如 560），按内容复杂度选，视觉舒服不拥挤。

## 表单与筛选行

- 输入框、下拉框、日期选择框：圆角 2px；**表单本身直角（0）**，卡片才用 12px；hover 描边 `#EE6402`。
- 筛选行：控件并入卡片标题行，与标题靠左对齐、上下居中；检索框旁必须有「查询」主按钮（不叫“检索”）。
- 日期检索文案全中文。
- 下拉列表：padding 4px 容器、项高 32px、padding `5px 12px`、圆角 2px；**hover 底 `rgba(0,0,0,0.04)`**；**选中项底 `#FFF4E6`、文字 85% 黑、无对勾**；第一项为「全部」；展开时箭头旋转 180°；列表阴影 `0 6px 16px rgba(0,0,0,0.08)`、1px `#d9d9d9` 描边。
- 下拉列表项字重 Regular。
- 表单标签去掉底色，文字 85% 黑。
- 弹窗内日期筛选样式与页面一致。

## 图表统计（数据报表稿 · 实测值）

- 页面结构：筛选行在卡片上方（库别/维度「按天」/日期/班次 下拉 + 查询主按钮 + 重置 + 右侧「导出数据/导出报告」描边按钮）；其下双卡片 342px 高并排（gap 16）：左「生产统计」flex:1，右「设备统计」宽 450px。
- 生产统计卡：白底、圆角 12px、规范阴影、padding `16px 24px 40px`（底部留 40px 给 x 轴标签）；标题 16px Medium + 副标题「型材(根)」12px `#737373`；右上角「当天」标注 14px `#BFBFBF` + 三系列圆形图例。
- 三系列（组内结构：**每组两根并排——入库（橙）独立一根；出库02（蓝）打底、出库01（绿）叠放同列（堆叠，绿底=蓝顶）**）：入库柱 `#F3A959` / 图例 `#F09330`，出库01 `#75D048`（柱/图例同色），出库02 柱 `#6CB3FF` / 图例 `#47A0FF`。柱子**直角**，槽位约 44px、柱宽 10px、两列间距 4px（按绘图区宽等比缩放）。
- 图例：**圆形色点 8px（用图例色）** + 文字 12px `#737373`，位于卡片右上角，点间距 12px；点击图例可开关对应系列（关闭时系列柱子淡化至 18% 不透明）。
- 坐标轴：y 轴刻度 DIN Alternate 12px `#E27400`，刻度值为 5 的倍数（0/5/10/15/20/25），上限按组内堆叠总和自适应取 5 的倍数；x 轴为 24 个小时段标签「0点-1点 … 23点-0点」，DIN Alternate 12px 45% 黑、锚定刻度右下点**倾斜 -15°**；网格线 `#F0F0F0` 1px。
- 悬停柱子显示数值提示：白底卡片、圆角 2px、阴影 `0 6px 16px rgba(0,0,0,0.08)`、12px、位于柱顶居中。
- 左右日期切换按钮：宽 24px、贴卡片内容区两侧（absolute，仅覆盖绘图区高度、不压标题）、1px `#EBEBEB` 描边、圆角 4px、白底；hover 描边与箭头 `#EE6402`；点击切换整天数据（当天/前一天/后一天）。
- 设备统计卡：标题 16px Medium；KPI 区 2 行 × 3 列，行高 72、标签 12px `#969696`、数值 DIN Alternate 24px/500/85% 黑、单位 12px `#737373`；一行最多 4 项、3 项时三等分。
- 交互：筛选行控件（库别/维度/日期/班次）均可点开（下拉列表、日期面板同全站规范）；点「查询」按当前条件刷新图表并 toast 反馈；「重置」恢复默认条件；卡片左右切换按钮按天翻数据并同步筛选行日期。
- 布局：图表区按真实页面比例保持固定宽度（生产统计图绘图区约 1255px，保证 24 个小时段标签倾斜后不散不开、不叠压），视口变窄时该区域横向滚动，不得压缩图表。

## 日期筛选

- 日期框：高 32px、白底、1px `#d9d9d9`、**圆角 2px**；hover/聚焦描边 `#EE6402`；文案全中文（开始日期 ~ 结束日期）。
- 日期面板：白底、圆角 2px、阴影 `0 6px 16px rgba(0,0,0,0.08)`、padding `12px 16px`；面板内全部 Regular。
- 月导航：‹ › 切换月份、hover 主橙；星期头 12px 45% 黑。
- 日期格子：28px 行高、圆角 2px；**今天=内描边 1px 主橙**（不填底）；**hover 底 #FDF4E7**；**选中=主橙实底白字**。
- 范围选择：第一次点击定起点、第二次定终点（早于起点自动交换）；两端实橙、中间日期底 `#FFF7E6`；可清空。
- 弹窗内日期筛选与页面一致；旁配「查询（主）+ 重置（描边）」。

## tab 切换按钮

- 按钮式页签：高 32px、padding 上下 4px 左右 16px、圆角 4px、14px Regular。
- 未选中：白底、1px `#d9d9d9` 描边、85% 黑文字；**hover 底 #FFF7E6 + 文字 #EE6402**。
- 选中：`#EE6402` 实底白字，hover 不变色。
- 灰轨道分段控件（视图切换）：轨道 `#F5F5F5`、padding 4px、圆角 4px；选中块 `#EE6402` 实底白字。
- 下划线式页签（antd Tabs，如「预排产 / 已下发」）：导航栏高 46px；页签 padding `12px 0`、项间距 32px、14px/500；未选中 85% 黑；hover 与选中均为 `#EE6402`；**选中指示条 `#EE6402` 高 2px**，切换时平滑滑动；底部整条 `#f0f0f0` 1px 分隔线。

## toast 提示

- 顶部居中、白底卡片、圆角 2px、阴影 `0 6px 16px rgba(0,0,0,0.08)`、padding `9px 16px`、14px Regular、icon 16px 与文字居中对齐。
- 语义色：成功 `#52c41a`、失败 `#ff4d4f`、警告 `#faad14`、信息/加载中 `#EE6402`（不用默认蓝）；加载中用主橙旋转圆环。
- 滑入滑出动效约 0.24s，2.4s 自动消失；同类型可堆叠。

## 异常 / 加载 / 空状态

- 加载中：三个主橙圆点脉冲动效（缩放 0.6→1、0.9s 错峰），用于表单切页过渡，避免布局抖动。
- 空状态：灰色占位图标 + 「暂无数据」45% 黑 14px，上下留白 32px。
- 加载失败：红色系提示条（底 `#fff2f0`、描边 `#ffccc7`、图标 `#ff4d4f`）+ 文字按钮「重试」。
- 行级数据异常用红色状态标签（见下）。

## 标签 / 开关 / 徽标

- 状态用胶囊开关呈现「启用/禁用」：高 22px、圆角 100px（antd Switch）；启用=主橙 `#EE6402` 实底 + 白字「启用」+ 白色圆钮在右；禁用=`rgba(0,0,0,0.25)` 底 + 白字「禁用」+ 圆钮在左；开关文字 12px 在框内。
- 任务状态标签 12px、高 22px、圆角 2px，用 antd 预设语义色（全部带浅色底+彩色描边）：
  - 排队中/待处理 geekblue：`#2f54eb` / 底 `#f0f5ff` / 边 `#adc6ff`
  - 进行中 processing：`#1677ff` / 底 `#e6f4ff` / 边 `#91caff`
  - 已完成 green：`#52c41a` / 底 `#f6ffed` / 边 `#b7eb8f`
  - 已异常 red：`#f5222d` / 底 `#fff1f0` / 边 `#ffa39e`
  - 已暂停 purple：`#722ed1` / 底 `#f9f0ff` / 边 `#d3adf7`
  - 无语义状态（已撤回等）：85% 黑文字、`#d9d9d9` 描边、白底
- 消息提示徽标：主橙实底白字小胶囊，内嵌在按钮框内。
- 复选框直角 14×14、hover 描边 `#EE6402`、选中实底白对勾（对勾视觉上下居中）；选中态与所在行联动（行背景 `#FFF7E6`）。

## 卡片

- 圆角 12px、规范阴影、背景白；左右内边距 24px、上下 16px。
- 卡片头标题 16px Medium 85% 黑，**不要**与 tab 切换按钮共用样式；标题与卡内下划线间距按 8px 网格。
- 卡片头下划线（如 `#d9d9d9` 1px）要么铺满两端，要么按稿留白，不两边随机留白。
- 统计卡片：标题间距与其他卡片一致；内容行自动均分（一行最多 4 项，3 项时三等分），数字用 DIN Alternate。

## 表单卡片（通用 · 含卡片标题）

- 卡片圆角 12px、规范阴影、左右 padding 24px；头 padding `16px 24px`，下接 1px `#d9d9d9` 分隔线**两端不留白**。
- 卡片头布局：标题 16px Medium 靠左；检索框 + 查询主按钮 + 重置按钮与标题**同行靠左、上下居中**；右侧操作按钮（导出/新建等）用 `margin-left:auto` 顶到最右，与检索组保持 8px 间距。
- 表体：表头 14px Medium、内容 14px Regular、85% 黑、单行不换行；首列与卡片标题左对齐（24px）、末列右 padding 24px；表头文字列与内容列左对齐。
- 卡片底部页码：右对齐、右 padding 24px、与表体间距 16px；**仅一页时不显示页码**。

## 导出交互模式

- 默认表格**不显示**复选框；点击「导出」后才进入导出模式：显示左侧复选框 + 同时展示导出方式（如 导出 Excel / 导出 CSV）+ 已选计数 + 取消。
- 导出内容为勾选行；未勾选则导出当前列表全部；CSV 带 BOM（`\ufeff`）防中文乱码，Excel 输出 .xls 表格。

## 通用交互

- 全站字体 Source Han Sans CN；除统计数字（DIN Alternate）与 antd 图标字体外不引入第三字体。
