# 型材立库中控系统（ROBIM PCCS 前端原型）

单文件、零构建、纯前端的工业中控系统演示原型。型材（角钢/型钢）按「船号 + 分段号 + 程序号」组织为切割包，覆盖库存看板、入库任务、加工任务、排产、数据报表、系统管理等页面。全部数据为演示假数据，无后端、无鉴权。

**当前版本：v10.10-13（2026-10-26）**

## 快速开始

- **双击 `中控系统.html` 即可运行**（无需安装任何东西，离线可用）
- 或起无缓存演示服务：`bash 启动演示服务.command`，然后访问 http://localhost:8088
- 设计规范预览页：http://127.0.0.1:8088/.kimi-code/skills/dajie-orange-design-spec/tools/设计规范总览.html

## 目录地图

| 文件 / 目录 | 用途 |
|---|---|
| `中控系统.html` | **主应用**（全部页面、组件、样式、交互都在这一个文件里） |
| `react.min.js` `react-dom.min.js` `dayjs.min.js` `antd.min.js` `antd.min.css` | 本地打包的依赖，主应用运行时必需，勿动 |
| `data.js` / `加工任务_假数据.js` / `排产_输入数据.js` / `排产_算法.js` | 演示数据与排产算法，主应用按固定顺序加载 |
| `中控系统_交付包/` | 可分发演示包（主页面 + 依赖 + 数据 + 启动脚本 + README），发客户用这个 |
| `AGENTS.md` | 常驻上下文（硬约束 + 当前进度锚点），**AI 助手开工前必读** |
| `项目档案.md` | 深度技术档案（模块说明、代码符号索引、风险清单） |
| `.kimi-code/skills/dajie-orange-design-spec/` | 大界橙色设计规范（skill 实体，唯一真实来源） |
| `同步设计规范.command` | 改完设计规范后跑一次：重建预览 + 推送到 Kimi 桌面端 |
| `迁移_Kimi/` | WorkBuddy → Kimi 迁移材料（交接文档 + 校验脚本） |
| `_归档/` | 低频存档：历史备份、验证探针、skill 旧版 |
| `型钢切优化/` | 历史工作区（软链 + 原始备份），非独立副本 |
| `排产仿真_中控.html` / `加工列表*.html` | 历史原型页（仿真页依赖缺失暂打不开，加工列表为主应用 iframe 外壳） |
